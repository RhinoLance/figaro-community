## Tune individual AGC parameters.
The page lists a series of tasks which can be used to tune each of the AGC 
parameters.

For each parameter, running the task will increment that parameter's setting.

E.g. when running the "Tune Threshold" task, if currently set to **S3**, it 
will advance to **S4**, then the next time **S5**.

:::note
If running firmware less than **1.04**, in order for the radio to apply the 
changes you will need to either enter and exit the menu or restart the radio.
:::
