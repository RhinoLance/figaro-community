Many AGC presets have been sourced from the QRP Labs groups.io mailing list.
They were offered by QMX operators for whom their perticular settings worked.

The names given to each preset were simpley that of a cartoon character that
for one reason or another seemed appropriate based on some impression of the 
description when the settings were published.

:::note
If running firmware less than **1.04**, in order for the radio to apply the 
preset you will need to either enter and exit the menu or restart the radio.
:::
