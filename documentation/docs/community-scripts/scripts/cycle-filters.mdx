<TabItem value="overview">

The script will retrieve a list of the radio's enabled filters, and cycle
through them on each run.

e.g.  Assuming you've enabled 200, 300, 500 Hz filters, every time you run
the script, it will cycle to the next highest filter.

200 -> 300 -> 500 -> None -> 200 -> 300 ...

If that's confusing, I'll be clear after you've run it several times.

Once run, the task's title will be appended with the active filter, with the
available filters set in the description.
