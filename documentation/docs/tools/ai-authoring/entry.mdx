# Agent Entry Point

If you're an AI coding agent, this is for you.  If you're a person, you may
find the [Tutorial](/docs/tutorial/intro) more useful.

The linked pages are the canonical, repository-independent contract for generating
Figaro Task Definition (FTD) JSON files.

## Read these pages in order
1. [Constraints](./constraints): strict schema and output-shape rules.
2. [Environment assumptions](./environment-assumptions): runtime API contract.
3. [Guardrails](./guardrails): safety and failure-handling rules.
4. [Testing strategy](./testing-strategy): validation and test checklist.
5. [QMX CAT Command](./qmx_cat_1.03):
referece to the radio's supported CAT commands.
